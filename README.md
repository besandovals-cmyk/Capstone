## Descripción del proyecto

Este proyecto consiste en el desarrollo de una aplicación web orientada a la gestión de inventario de equipamiento y al registro de mantenimiento de vehículos de Bomberos de San Bernardo.

La iniciativa surge de la necesidad de mejorar el control de información que anteriormente se gestionaba mediante planillas Excel, facilitando su organización, consulta y seguimiento.

El sistema se desarrolla inicialmente para una compañía, considerando la posibilidad de ampliar su utilización a otras compañías en el futuro.

## Objetivo general

Desarrollar un sistema web que permita administrar el inventario de equipamiento, registrar las mantenciones de los vehículos y controlar los gastos asociados, contribuyendo a una gestión más organizada y centralizada de la información.

## Funcionalidades del sistema

- Gestión de inventario de equipos y materiales.
- Registro de vehículos y mantenimiento.
- Control de gastos y reparaciones.
- Alertas de vencimiento de equipamiento.
- Checklist diario de vehículos.
- Registro y valorización de pérdidas de inventario.
- Importación y exportación de información mediante Excel.
- Inicio de sesión y control de acceso según roles.
- Separación de información por compañía.
